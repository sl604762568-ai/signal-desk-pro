# v6.11.2 独立加载修复

这版处理三个可复现的结构性问题：次日5股在 HTTP 请求线程同步拉大量K线和板块成分、板块源集体失败时看不到已有历史快照、前端无限显示「扫描中」。

- `/api/next5` 首次返回 `loading:true`，单独线程分析，成功且有真实候选才冻结；每5秒轮询，70秒后提示明确诊断。
- 明日5股的板块成分检索及K线研究池减量，降低免费服务器压力；这不等于扫描整个A股市场。
- `/api/sector-review` 若东方财富板块接口全部失败，只显示本网站已经存储的真实历史数据，没有历史则明确显示不可用。
- `/api/health` 新增 `next5` / `sector_review` 状态，便于定位接口失败源。
- 本修复不能保证第三方行情恢复、准确覆盖全A市场，也不能防止 Render Free 重新部署造成 SQLite 历史丢失。

上传全部解压后文件到原仓库，等 Render Live，再先看 `/api/health` 中版本 `6.11.2-independent-modules`。若板块仍无数据，请将健康检查中 `sector_review.error` 和 Render Logs 中首次报错时间发来，避免继续盲改。
