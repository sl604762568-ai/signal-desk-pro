# Signal Desk Pro v6.5

本版在 v6.4.2 的稳定数据链路基础上新增：

- **次日联动5股**：海外/宏观事件 → A股情绪 → 板块情绪 → 事件驱动 → 量价 → MACD/均线，最后输出 5 只研究候选。
- 自动排除 **688 开头**、ST/退市标记及低流动性股票。
- **单股搜索栏**：支持输入股票代码或名称。
- **单股技术诊断**：MA5/10/20/60、MACD、RSI14、量能、20日高低点。
- **缠论近似结构**：分型、摆动、中枢、二买/三买观察信号。
- K线图上叠加均线、中枢区间、分型点与 MACD。
- 后续走势采用三种条件路径：偏强、震荡确认、结构失效，不做确定性价格预测。
- 原有“技术性选股”“AI复盘选股”“缠论二买/三买候选”继续保留。

## 新接口

- `/api/next5`：生成次日联动5股
- `/api/search?q=600487`：股票搜索
- `/api/analyze/600487`：单股技术+缠论诊断
- `/api/health`：版本应显示 `6.5-linked-next5-search`
