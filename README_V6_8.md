# Signal Desk Pro v6.8 · 板块复盘 / 情绪流转 / 多级别缠论

## 新增

1. **收盘板块复盘**
   - 概念 + 行业板块热度排名。
   - 热度由板块涨跌幅横截面、上涨家数占比、主力净占比/净流入、换手和新闻热度辅助组成。
   - 点击板块可展开真实成分股，默认按当日涨幅降序。

2. **真实板块关系**
   - 板块 → 个股使用东方财富 `BK` 板块成分关系。
   - 个股 → 板块使用个股行业字段 + 概念列表。
   - 不按股票名称关键词猜“芯片/科技/机器人”等概念。
   - 一只股票可以同时属于多个概念。

3. **板块情绪流转**
   - 新增最近若干交易日的板块领涨路径。
   - 网站每天运行后将 Top 板块写入 `sector_snapshots`，历史积累后优先使用真实收盘快照。
   - 数据库尚未积累足够历史时，用当前高热板块的历史板块 K 线生成样本流转路径，并明确标注为样本。

4. **个股分析增强**
   - 搜索/板块成员/次日5股都进入同一分析引擎。
   - 日线 = 小级别；周线 = 大级别，可切换。
   - 两个级别均显示 K 线、MA、MACD、缠论笔、中枢与机械趋势线。
   - 增加行业/概念真实关系、行业热度分析、公司关系分析。

5. **次日5股改为板块先行**
   - MKT 环境门槛 → 高热板块 → 真实板块成分股 → 短线弹性/量价 → MACD/均线/缠论确认。
   - 仍排除 `688`、ST/退市和极端流动性样本。
   - 如果板块关系源临时不可用，才降级到旧行业/新闻匹配逻辑。

## 新接口

- `GET /api/sector-review?limit=12`
- `GET /api/sector/{BK代码}`
- `GET /api/analyze/{股票代码}`（新增多级别、板块关系和行业/公司分析）
