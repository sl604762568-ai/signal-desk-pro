# Signal Desk Pro v6.13 — 复盘/龙虎榜/龙种/14:30尾盘/VIX-VXN

本版建立在 v6.12.2 可部署分支上，重点修复数据源失败时的降级体验，并强化收盘复盘与次日/尾盘研究。

## 本版修复

1. **竞价历史补采**：`/api/auction25/backfill` 不再要求 CONTROL_TOKEN。补采只写可重建的真实市场缓存，仍不允许用模拟竞价替代历史 09:25 正式撮合。
2. **龙虎榜席位**：逐席位明细增加机构、北向、量化关键词和公开营业部名称标签；包括“紫阳东路、桑田路、上塘路、金开大道”等关键词。标签只对应公开营业部名称，不推断自然人身份。支持“机构共振 / 游资合力 / 明日观察”。更新按钮强制绕过10分钟服务端缓存。
3. **明日5股**：修复缠论 signals 为对象时导致后台异常的问题；扩大真实候选预筛池并增强三日题材轮动、资金角色权重。若真实K线可用候选>=5，将固定输出5只；盘后首次结果仍按交易日冻结。卡片展示题材、技术、缠论和风险理由。
4. **板块复盘降级**：Eastmoney clist 被风控时，优先显示本站已经保存的真实板块快照；若当前无板块快照，则收盘复盘使用真实涨停池题材聚合，不展示未取得的资金字段。
5. **量价复盘候选**：降低已经大幅扩张的股票优先级；20日累计涨幅、偏离MA20过大时显著降分或剔除，更偏向尚未过度扩张的结构。
6. **龙种角色族谱**：三日题材轮动下增加空间龙、周期龙、换手龙、日内龙/点火者、补涨龙、承接者/中军、穿越龙、撤退龙。分类为程序化复盘标签，不代表确定性评价。
7. **14:30尾盘研究**：新增 `/api/intraday-1430`，在14:20–14:55优先筛选未涨停、短线不过热、题材仍活跃且技术结构尚有空间的5只研究候选。页面打开时尾盘窗口自动触发；Render Free休眠时无法保证无人值守定时运行。
8. **VIX/VXN海外风险对照**：新增 `/api/global-risk`，展示VIX、VXN、标普500、纳斯达克、道琼斯与A股情绪对照。VIX/VXN尝试Yahoo，失败时降级到Cboe每日历史；用于风险环境说明，不转化为涨跌概率。

## 数据原则

- 行情、价格、竞价、龙虎榜、涨跌停及K线不使用模拟数据冒充实时数据。
- 数据源失败时显示真实历史快照、真实涨停题材聚合或“暂不可用”。
- 借鉴 a-stock-data 的数据源优先级思路：实时行情/K线尽量使用腾讯等较稳定节点，Eastmoney只承担其独有的板块/龙虎榜等数据，并做好缓存、限流和降级。
- “游资”标签仅基于公开营业部名称关键词，不能据此认定具体自然人实际操作。
