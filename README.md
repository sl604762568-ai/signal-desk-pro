# Signal Desk Pro v6.1 — AI复盘选股 + 缠论二买/三买

本版在 v5 的热点链路、情绪周期、短线量价候选基础上新增：

- **AI复盘选股按钮**：仅点击后运行，避免首页每次加载都扫描历史K线。
- **全市场自适应策略**：根据市场强/中/弱，动态调整趋势龙头、缩量回踩、平台放量突破、轮动初启的权重，不再限定电力板块。
- **缠论结构候选**：单独展示“缠论二买候选 / 缠论三买候选”。
- **二买机械近似**：前低 → 明显反弹 → 更高的回踩低点，近期重新转强。
- **三买机械近似**：自动寻找三段摆动重叠形成的中枢近似区间，向上离开后回踩不有效跌回中枢上沿。
- **结构失效提示**：二买跌破最近回踩低点、三买重新跌回中枢上沿会在风险项中明确显示。

> 缠论自动化存在不同划笔/线段口径。本模块属于程序化筛查层，用来缩小人工复盘范围，不等同于严格人工缠论定性，也不构成证券交易建议。

公网部署版：把「热点链路」与 A 股情绪周期、财经新闻雷达、短线量价候选池整合到一个手机/电脑自适应网页。

## 直接部署

- Render：根目录已经提供 `render.yaml` + `Dockerfile`，推荐区域 `Singapore`。
- Railway：根目录已经提供 `railway.json` + `Dockerfile`。
- 两个平台部署完成后都会得到 HTTPS 公网地址，不再使用 `127.0.0.1`。

详细步骤见：`DEPLOY_PUBLIC.md`。

## 核心接口

- `/`：工作台首页
- `/api/dashboard`：行情、新闻、热点链路、候选池聚合
- `/api/stock/{code}`：近 70 个交易日 K 线
- `/api/health`：公网部署健康检查

## 环境变量

见 `.env.example`。

## 数据回退

真实行情 / 新闻 / 原热点站任一上游失败时，系统会保留页面并回退演示结构，不会因为单一数据源错误导致整站白屏。

## 提示

候选评分表示研究优先级，不预测收益，不构成交易指令。实时价格与成交信息以交易所和交易软件为准。

## v5 个股分析增强
- 候选池直接显示真实股票名称、代码、现价、涨幅、量比、换手率、成交额。
- 候选分为：首板强势 / 连板接力 / 趋势突破 / 放量异动 / 强势跟踪。
- 展示 5/10/20 日趋势结论、热点匹配、量价触发理由、结构风险。
- 数据源单点失败不再导致全站切演示；全 A 行情支持东方财富失败后回退新浪。
- 评分仅表示研究优先级，不构成买卖建议。
