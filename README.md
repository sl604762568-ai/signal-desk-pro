# Signal Desk Pro v6.4 — 公共直连数据源稳定版

这一版专门修复 Render 上“网页能打开，但真实行情长期加载不出来”的问题。

## 核心变化

- **实时核心不再依赖 AKShare**，也不再让某个第三方 SDK 阻塞整个后台。
- 全 A 快照主源：**新浪财经行情中心直连**。
- 个股日 K / MA / 量价 / 缠论历史：**腾讯财经 K 线**，失败后自动回退**新浪 K 线**。
- 腾讯 K 线使用 3 个入口依次回退：`web.ifzq` → `proxy.finance.qq` → `ifzq`。
- 所有网络请求都有硬超时，真实数据抓取仍在独立子进程执行。
- 新增 `/api/sources`：直接显示新浪列表、股票总数、腾讯 K 线当前是否可访问以及耗时。
- 新增数据覆盖率标记：如果只拿到部分真实股票，网页明确显示“部分真实数据”，不会假装是完整全市场广度。
- 去掉 AKShare 依赖，Render 构建更快、包更小。
- Service Worker 缓存版本升级，部署后自动清旧缓存。

## 数据真实性原则

- 演示数据只用于页面骨架，状态会明确标记“回退/演示”。
- 真实行情不足时，不用演示股票冒充真实个股候选。
- 如果新浪全市场快照覆盖不足 80%，上涨/下跌家数不参与情绪评分，避免用偏样本误判大盘。
- 昨日涨停溢价、精确晋级率等在没有可靠源时显示 `--`，不会凭空估算。

## 核心接口

- `/`：工作台
- `/api/health`：版本、后台刷新状态
- `/api/sources`：数据源连通性诊断
- `/api/dashboard`：非阻塞聚合数据
- `/api/dashboard?mode=demo`：演示骨架
- `/api/stock/600519`：个股近 70 交易日日 K
- `/api/review-picks`：按钮触发 AI 复盘 + 缠论二/三买候选

## 部署

把本目录全部覆盖上传到原 GitHub `signal-desk-pro` 仓库并 Commit。Render 已经连接该仓库时会自动部署。

部署成功后先看：

1. `/api/health` 中 `version` 应为 `6.4-direct-public`
2. `/api/sources` 检查 `sina_list`、`sina_count`、`tencent_kline`
3. `/api/dashboard` 第一次会立即返回页面结构并后台刷新，通常数秒到几十秒切为真实数据

> 新浪/腾讯这里使用的是公开网页数据接口，不是交易所正式授权行情 API，接口可能调整或限流。适合个人研究与复盘；关键交易数据仍应以券商/交易所终端为准。
