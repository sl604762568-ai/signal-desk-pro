# Signal Desk Pro v6.15 · 白色量化研究工作台

- 全站白色专业交易终端视觉，压缩页头和卡片间距，提高PC/手机单屏信息密度。
- PC个股分析：左侧K线固定，右侧研究卡片独立滚动；手机自动变单列。
- GET只读接口增加短时内存缓存与并发去重，减少重复数据请求。
- 单股分析新增 BOLL、KDJ、ATR、ADX、CCI、WR、MFI、OBV、BIAS，并保留 MA、MACD、RSI、量能。
- 分析新增“大盘情绪/市场广度 + 板块题材热度 + 技术指标 + 缠论”的交叉核验。
- 缠论仍是程序化近似结构，不把二买/三买识别当成确定性预测。

部署后 `/api/health` 应显示 `6.15-white-quant-workbench`。首次上线建议浏览器强制刷新。
