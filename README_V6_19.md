# Signal Desk Pro v6.19：数据链路与量价榜单修复

## 本次调整
- 情绪页：真实行情冷启动时显示「真实行情采集中」，不将演示数字或未就绪状态伪装为实时市场情绪；实时源成功后自动按现有逻辑刷新。
- 跨页面点击个股：统一进入 `/stocks?stock=六位代码`，触发多级别 K 线、技术指标与缠论近似分析；同页候选使用完整研究视图。
- 量价技术扫描：新增综合、技术、题材、缠论、风控的独立排序入口；当前严格扫描 API 不包含的维度显示 `-- / 待核验`，不会填充默认 50 分，也不会凭缺失数据产生排名差异。
- 竞价：归档量、命中量及补采运行阶段的显示更清楚。历史字段不齐全时不会按缺失值判定为符合条件；过去未归档、历史源不提供的 09:25 正式撮合数据无法凭代码还原。
- 预加载：将前端模块预热请求分 3 批，减轻 Render 免费实例瞬时并发压力；已有服务端有效缓存仍按原机制复用。
- 雷达图：大盘和题材没有实际评分时展示 `--`，不显示默认的 50 分。

## 尚需后续验证与接入
- 目前板块行情仍高度依赖东方财富的公共接口。已有的 `terminal_explorer` 对当前进程成功请求的数据做短期缓存和过期展示，`sector-review` 可退到真实涨停题材/历史快照；**不是独立稳定的实时备用供应商**。彻底解决需要有授权、可核验的备用板块数据源及持久化存储。
- 情绪与竞价真实覆盖度取决于 09:25 是否采集成功及服务器运行时间。Render 免费实例休眠时可能错过采集窗口。
- 量价榜单中技术/题材/缠论/风控评分需在扫描流程接入同日的原始指标、板块归属和风险字段；当前缺失时不产生虚构的高分榜。
- 情报与板块同日事件效果回测（在新闻发布时点之后统计股价/板块反应，严格防前视偏差）尚未上线；现有新闻热度不等于市场反应。
- 尚未通过真实 Render 上线联调；部署后请按 `api/health`、`/emotion`、`/auction`、`/sector`、`/stocks` 依次验收。
