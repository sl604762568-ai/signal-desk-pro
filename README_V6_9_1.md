# Signal Desk Pro v6.9.1 — 手动 + 自动虚拟盘 / 实时行情修复

## 本版重点

1. 回到 v6.9 分支，不依赖 Render 付费常驻实例。
2. 虚拟盘增加手动买入、卖一半、全部卖出。
3. 手动买卖的成交价由服务器实时查询腾讯财经，前端不能自行提交价格。
4. 自动虚拟盘每次只查询“当前持仓 + 最近次日候选”的少量股票，不再等待全 A 实时快照。
5. 首页真实行情刷新使用新浪快速真实股票池，减少全市场 70+ 页分页造成的阻塞。
6. A 股规则：买入 100 股一手；卖出模拟 T+1；手续费、卖出印花税、滑点继续计入。
7. 手动交易与自动交易共用同一虚拟本金、持仓、成交记录和净值曲线。

## 手动交易

进入“虚拟盘”模块：

- 输入 6 位股票代码；
- 点击“查询实时价”；
- 可填写买入金额，系统自动换算可买整手数量；
- 或填写指定股数（100 的整数倍）；
- 点击“虚拟买入”；
- 持仓表中可“卖一半”或“全部卖”。

所有手动操作均为纸面交易，不连接券商，不产生真实证券委托。

## 实时数据说明

- 手动交易/虚拟盘持仓估值：腾讯财经小范围实时行情。
- 首页热点候选池：新浪财经快速实时股票池。
- 单股历史 K 线：腾讯财经，失败时回退新浪 K 线。
- 公开数据源可能临时不可用；页面会显示错误，不会把演示数据冒充实时成交价。

## Render 免费版

本版可以继续使用 Render Free。免费实例休眠时不会无人值守运行自动策略；重新访问网站后服务会唤醒。手动交易和页面打开期间的自动检查不受“必须付费”限制。
