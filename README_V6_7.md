# Signal Desk Pro v6.7 — 超短弹性选股修正版

本版重点修复“次日5股偏向高股价/大盘股”的问题。

## 核心变化

- 股价绝对值不再作为正向评分。
- 接入新浪实时快照中的 `nmc`（流通市值）和 `mktcap`（总市值）。
- 次日5股优先短线弹性：流通市值、换手率、量比/相对5日均量、成交额区间、当日涨幅区间。
- 成交额不再越大越加分；过大的成交额会降低短线弹性评分。
- 有流通市值数据时，默认过滤约 10~320 亿元，甜蜜区间约 25~120 亿元。
- 当前偏好排除股价 >80 元（只是超短偏好过滤，不代表高价股质量差）。
- 继续排除 688 开头、ST/退市标记。
- 次日5股排序不再用成交额作为最终 tie-breaker。
- 卡片新增“流通市值 / 量比 / 换手 / 短线弹性”。
- 原有技术性选股、MACD/均线、缠论笔、中枢、二买/三买全部保留。
