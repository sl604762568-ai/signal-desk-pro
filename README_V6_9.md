# Signal Desk Pro v6.9 — 虚拟盘 / 纸面交易

新增“虚拟盘”模块，只做模拟成交，不连接券商、不发送真实订单。

## 核心流程

1. 每日收盘后保存网站的“次日5股”为下一交易日信号。
2. 下一交易日用真实行情快照检查候选：市场门槛、综合分、板块强度、短线弹性、技术面、跳空与关键支撑。
3. 满足条件时按 100 股一手模拟买入；不满足则跳过。
4. 持仓按止损、止盈、移动止盈、关键支撑/MA20、最长持仓天数自动模拟卖出。
5. 记录现金、持仓、手续费、印花税、滑点、成交、净值曲线、胜率、最大回撤与盈亏比。

## 默认参数

- 初始本金：¥10,000（最低 ¥10,000）
- 最大持仓：3
- 单仓目标：33%
- 止损：5%
- 止盈：8%
- 移动止盈回撤：4%
- 最长持仓：5 天
- 最低次日候选分：65
- 佣金：0.03%，最低 ¥5
- 卖出印花税：0.05%
- 模拟滑点：0.10%

以上均为模拟参数，可在页面中调整，不代表交易建议。

## “回测”的口径

本模块优先做**前向回测 / 纸面实盘**：从启用之日起真实记录每天网站实际生成的次日5股和后续虚拟成交，不倒推不存在的历史事件/板块/新闻信号。

可以查看 7 / 30 / 90 / 180 天的：
- 净值曲线
- 区间收益率
- 最大回撤
- 胜率
- 盈亏比
- 成交明细

## 自动运行限制

服务端每 60 秒检查一次虚拟盘；网页打开时浏览器也会每 60 秒触发一次检查。

如果使用 Render 免费实例，实例休眠期间后台线程不会运行，因此它不能保证像券商服务器一样 24 小时连续监控。要做稳定的盘中自动纸面交易，建议后续使用不休眠的服务或定时任务。

## 数据持久化

当前沿用 SQLite。如果 Render 使用临时磁盘，重新部署或实例重建可能丢失虚拟盘记录。长期使用建议迁移到 PostgreSQL / Supabase 或 Render Persistent Disk。
