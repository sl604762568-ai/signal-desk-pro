# Signal Desk Pro v6.14 · 多页面工作台重构

本版以 v6.13 为基础，不删除原有复盘、龙种、龙虎榜、竞价、板块、选股、单股分析、尾盘、VIX/VXN 和虚拟盘能力。

## 新增多页面路由

- `/market` 今日市场：收盘核心复盘、连板梯队、三日题材轮动、明日5股、14:30尾盘
- `/emotion` 情绪周期：市场情绪、晋级生态、广度、VIX/VXN环境对照
- `/dragon` 龙虎榜：公开龙虎榜与席位资金
- `/auction` 竞价中心：09:25真实竞价、题材分析与历史补采
- `/sector` 题材板块：行业/概念/风格/地域/热点、板块复盘与轮动
- `/stocks` 个股与选股：自选、单股诊断、AI复盘、组合选股、历史股性扫描
- `/intel` 情报中心：热点链路、实时新闻、海外风险环境
- `/tools` 策略工具：虚拟盘与回测

根路径 `/` 保持兼容并默认按“今日市场”展示。

## 稳定性改动

旧版首页会错峰但仍自动请求大量模块。本版只自动加载当前页面需要的重型接口，减少 Render 实例首次加载时的并发、第三方行情源同时连接数量和单页失败扩散。

所有原有 API URL 保持不变，避免后端模块大拆后引入新的数据错误。
