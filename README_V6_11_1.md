# v6.11.1 收盘复盘加载修复

修复：`/api/close-review` 不再在 HTTP 请求中同步等待八路公开数据。首次请求立刻返回 loading，单独后台线程采集，约 6.5 秒轮询；达到 35 秒预算后返回明确超时，不会展示未校验数字。其它模块错峰启动以降低 Render 免费实例并发压力。升级 Service Worker 缓存版本。

部署后： `/api/health` 检查版本 `6.11.1-nonblocking-review`，再打开 `/api/close-review`，首次应快速返回 loading。若数据源本身不可用，仍可能显示“暂不可用”；这不等于修好了第三方源。

**重要**：Render Free 若实例休眠，后台线程不会运行；SQLite 在重新部署/实例更换后不保证持久性；这版未增加真实数据源授权，也不保证公开接口永远可达。
