# Signal Desk Pro v6.10 — 复盘优先版

本版把页面核心重新聚焦到：**收盘复盘 → 明日5股 → 单股深度分析**。虚拟盘/自动回测移到页面最后，仅用于验证策略。

## 关键变化

1. **收盘核心复盘**
   - 涨停 / 跌停使用专门涨跌停池，不再用全A快照近似推算。
   - 连板梯队精确列出股票、板数、题材/涨停原因。
   - 最高连板与开盘红“涨停天梯”交叉校准。
   - 1进2、2进3、3进4、4进5、5进6晋级率按前一交易日与当日名单计算。
   - 资金角色：龙头、中军、日内龙、助攻、后排、首板潮。

2. **题材轮动固定比较3个交易日**
   - 今天 + 前1个交易日 + 前2个交易日。
   - 识别：新发酵、增强、延续、分歧、退潮。
   - 同时显示“涨停题材轮动”和财联社板块轮动作为独立参考。

3. **多源校准**
   - 东方财富涨停/跌停池
   - 财联社涨停原因/市场情绪
   - 开盘红市场情绪、涨停复盘、涨停天梯、历史涨停
   - 同花顺人气榜作补充
   - 上交所/深交所公开规则与技术接口作为交易日、证券代码、涨跌幅规则参考
   - 当关键源冲突时，页面显示“校验未通过”，不发布猜测数字。

4. **明日5股与单股分析**
   - 保留板块、量价、市场环境、事件面、技术面、MACD/均线、缠论等逻辑。
   - 单股分析继续支持日线/周线、缠论笔、中枢、趋势线、二买/三买近似结构、行业/公司关系。

5. **自动回测放到最后**
   - 手动/自动虚拟买卖保留。
   - 每笔交易日志增加：购买/卖出时间、决策理由、技术面摘要、题材/信息面摘要。

## 部署

覆盖原 GitHub 仓库后让 Render 自动部署。部署成功后检查：

- `/api/health`：版本应为 `6.10-review-first`
- `/api/close-review`：返回收盘复盘结构；若关键源不一致，会返回 `verified: false`

> 注意：当前免费 Render 的本地 SQLite 数据不保证跨重新部署长期保存。此版暂不引入外部数据库，按用户要求先优化复盘与选股体验。
